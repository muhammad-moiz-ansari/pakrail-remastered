# CS3014 D4 Accessibility Audit

**Test date** November 4, 2026 (Asia/Karachi). **Browser** Chromium-based ChatGPT in-app browser, real browser tabs controlled with CUA keyboard input and browser Playwright locators. Browser version was unavailable. Part A used only untargeted keyboard input. The primary Part B run used keyboard input and one targeted focus action to recover the arrival chooser, documented in B01. A second Part B evidence run used targeted browser controls and a wider window. Focus observations came from the browser accessibility tree and visual indicators from rendered screenshots. No app source or Word report was edited.

**Build tested** Git HEAD `06c3811ed0583cedd9425872637c6b1c2c37726d` (`feat: build Designify rail booking prototype and documentation`), with pre-existing working-copy entries `.gitignore`, `next-env.d.ts`, and `public/vendor/`. Part A HTML SHA-256 `ADC00226A3FD5E5313A94925ABEB5C7AB3E6F699575A7A47D39C8FC5B2517654`. Part B was the local Next.js development build, with Next.js 16.4.3/Turbopack reported by the startup attempt. This checkout exposes the self-contained D4 demo.

## Startup and scope

- Ran the documented `npm run dev` (package command `next dev --hostname 127.0.0.1`). Port 3000 already had a Next dev server from this exact working directory, PID 13636. The new process tried port 3001, detected the existing instance, and exited. The audit used the existing server at [127.0.0.1:3000](http://127.0.0.1:3000/).
- Attempted `python -m http.server 3011 --bind 127.0.0.1 --directory public`, then `python -u -m http.server 3011 --bind 127.0.0.1 --directory public` with localhost access. The browser timed out on that port. Direct file navigation was blocked by the browser URL policy. The direct [Part A HTML URL](http://127.0.0.1:3000/part-a/index.html) worked and displayed the grayscale artifact, independently of the green app flow.
- Part B primary run used Lahore Junction → Rawalpindi, November 5, one way, Mehran Explorer, Economy and three fictional adults. The screenshot repeat used November 4, Emerald Night and Economy with the same three names and seat changes. The two fares therefore differ.
- Part A reached its static confirmation. Part B reached functional demo confirmation with reference `DFY-063392A0`. No login or hosted checkout appeared in this tested build. Demo payment explicitly needed no card or bank details. No real payment was attempted.
- Tab counts refer to the indicated starting focus. “Deferred” records an issue left for future work. “Resolved in B” describes an observed difference between builds. This audit made no fixes.
