## Proposed first file (review before apply)

`data/catalogue/review/stations.public-review.json` contains six observed names, source URL, date-precision retrieval/verification timestamps and per-field metadata for the local visibility flag. Official station codes are omitted, cities unknown (`null`), aliases empty. IDs reuse existing internal prototype identifiers to preserve UI state; they are not official codes. `active: true` means locally visible in station search, with manually-entered/unverified field provenance, not a claim of live railway operation.

The database-aware dry-run report is `docs/backend/first-station-dry-run.txt`: **6 proposed inserts, 0 updates, 0 unchanged, 0 rejected**. No rows were applied during that initial review. Following explicit user approval on 2026-11-02, all six records were imported after index initialization. `approved-station-postcheck.txt` confirms all 6 are now unchanged; `live-station-api-check.txt` confirms successful MongoDB-backed API lookup of each record. Existing fixture labels such as “Islamabad Margalla” differ from the observed `MARGALA`; the import deliberately retains the official UI spelling rather than silently calling the old display label verified.
